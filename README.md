# COLAE

MVP da plataforma de orçamentos da COLAE.

## Stack
- Next.js + React + TypeScript
- pnpm workspaces
- Motor de preços server-side em `packages/pricing`
- CI via GitHub Actions
- Deploy preparado para Vercel

## Fluxo
Produto → Material → Tamanho → Quantidade → Acabamento → Faca → Cálculo → Orçamento.

Os valores atuais do catálogo são parâmetros de demonstração e devem ser substituídos pelos custos reais da COLAE.
